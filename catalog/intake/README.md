# 候选库

这里保存自动发现、人工投稿和旧目录迁移记录，不会直接进入公开网站，也不会执行候选仓库中的脚本。

当前 `40` 份 YAML 记录来自个人站 `brand-marketing-skills` 的旧目录迁移。`promoted` 只表示已找到对应的 V1 公开 Skill；其他记录仍需逐项完成：

1. 真实 `SKILL.md` 路径；
2. 明确的内容许可证；
3. 单独安装与单独触发；
4. 品牌 0→1 任务相关性；
5. 输入、输出、人工决定与不能推断的内容；
6. Codex 与 Claude Code 安装测试；
7. 维护者人工核对原文。

GitHub Star、作者知名度和自动安全扫描结果都不能单独成为上线理由。候选进入 `catalog/skills/` 必须通过 PR，由维护者人工决定。
