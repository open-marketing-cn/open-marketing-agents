# 来源与样本计划（必需）

在任何采集或分析之前，先输出并请用户确认以下表格：

| 项目 | 必须填写 |
|---|---|
| 品牌或品类 | 明确到用户能判断是否跑偏 |
| 研究问题 | 只保留 1–3 个具体问题 |
| 目标市场 | 中国大陆或明确的出海市场 |
| 时间窗口 | 起止日期或“最近 N 天” |
| 公开表达来源 | 平台、内容类型、预计数量 |
| 购买/使用评论来源 | 平台、产品范围、预计数量 |
| 搜索词 | 品牌词、品类词、问题词、场景词 |
| 排除项 | 无关同名、招聘、招商、水军/重复等 |
| 身份字段 | 默认删除头像、主页、账号 ID、设备、精确位置 |
| 停止条件 | 达到数量、达到时间/费用上限或来源失效 |

## 样本规则

- 不把 API 返回的前 N 条当成随机样本。
- 记录排序方式、搜索词、时间和分页范围。
- 至少包含一个公开表达来源和一个购买/使用评论来源。
- 只有一个平台时，结论必须标注“单平台样本”。
- 来源集中在单一品牌、单一商品或单一活动时，不外推到整个品类。
- 数据量很大时可以分批采集；每批保留独立原始文件和采集时间。

用户确认计划后才进入采集。
