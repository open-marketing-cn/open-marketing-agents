# 怎样找到用户并判断增长是否有效

把内容、入口和使用行为连起来，用一次实验决定下一轮投入。

:::takeaways 先看结论

- **分清被看见与被使用**：收藏、询问和成交不是同一件事。
- **一次实验回答一个问题**，内容、入口和观察行为要接得上。
- **有效一次后检查能否复现**，把未知来源和全部成本记下来。

读完完成：**增长实验记录**，用实际行为决定下一轮投入。

:::

*兴趣还需要一个能承接住它的入口。*

## 01 · 先找出用户在哪一步停住

:::steps 从触达到再次使用

1. **被看见**：内容触达了匹配的人吗？
2. **进入**：有清楚、承诺一致的下一步入口吗？
3. **完成任务**：产品承接住兴趣了吗？
4. **付款或回来**：价值、购买条件与重复使用需要成立吗？

:::

| 卡在哪里 | 优先检查 |
|---|---|
| 看见却不进入 | 人群是否匹配、内容与入口是否清楚 |
| 进入却完不成任务 | 回到交付流程找卡点 |
| 能用却不购买 | 使用频率、价格、替代方案、采购流程 |
| 用过却不回来 | 任务是否真的重复发生 |

:::details 进一步理解 · 指标怎样对应下一步决定

产品可以完成任务以后，增长要回答的是：怎样持续接触有这项任务的人，让他们理解结果、尝试使用，并在适合时购买或回来？这个过程跨越内容、渠道和产品，任何一段缺失，都可能让前面的投入停在表面数据上。

本章不提供适用于所有产品的流量公式。你会选择一个当前可接触的渠道，围绕一个具体问题设计实验，再用记录决定继续、调整或停止。先获得一段可以解释的过程，比同时尝试许多渠道更容易学习。

把最近一次触达拆开看：内容被看见，用户进入介绍页，开始尝试，完成任务，付款，之后再次使用。不同业务可以合并或调整步骤，但不能把收藏、询问和成交当成同一件事。

如果很多人看见却没人进一步了解，检查内容是否吸引了匹配的人，以及下一步入口是否清楚。如果有人进入却无法完成任务，回到第三章修产品。如果能完成任务却不愿购买，则需要了解使用频率、价格、替代方案和购买流程，而不是只改标题。

每次只选择当前最需要弄清的一段。追踪一长串指标却没有对应决定，只会增加记录成本。一个好的指标应能帮助你回答：发生了什么，接下来要改哪里？

:::

## 02 · 让一条内容回答一个问题

从访谈、反馈或搜索问题里选题。**教程讲怎样完成，比较讲选择条件，案例讲过程与边界。** 下一页要兑现内容入口的承诺。

发布前写明它承担哪一步：帮助理解场景，还是帮助购买决策。别把所有阅读都算商业进展，也别只用当天成交评价每条内容。

:::details 进一步理解 · 内容与入口怎样衔接

选题可以从访谈、使用反馈和真实搜索问题中来。先写出读者正在解决什么，再决定展示什么内容。教程适合展示任务怎样完成；比较适合解释选择条件；案例适合说明过程与边界。内容形式应由问题决定，而不是因为某种格式正在流行。

接着安排一个自然的下一步。读完教程可以试用对应模板，了解方案后可以查看结果样例。入口承诺的东西，要与下一页实际提供的内容一致。不要让用户为了完成一个小任务，被迫理解你所有的产品功能。

内容也有不同观察目标。有些帮助新用户理解场景，有些接近购买决策。把它们都按当天成交评价，会误判前者；把所有阅读都算作商业进展，又会高估后者。发布前写明这条内容承担哪一步。

:::

## 03 · 用一个实验减少一项不确定性

1. 明确本轮要改善的行为和目标人群。
2. 选一个当前可触达的渠道与对应入口。
3. 固定主要条件，改变一个值得测试的因素。
4. 记录行为、观察窗口及时间费用上限。
5. 到约定时间回看，决定继续、调整或停止。

**记录数量，也记录分母与观察期。** 链接来源和用户自报分开保存，无法追踪的写“未知”。小样本不能包装成严密对照实验。

:::details 进一步理解 · 样本、归因和延迟购买

选择一个渠道、一类人群和一个主要假设。写清发布或接触方式、时间、承接入口、观察窗口及成本上限。条件同时变化太多时，即使结果改善，也很难知道改善来自哪里。

1. 明确要改善的行为，例如完成首次任务。
2. 选择与这项任务相符的人群和内容入口。
3. 固定主要条件，改变一个最值得测试的因素。
4. 记录触达、后续行动、时间和投入。
5. 到约定时间回看，并写下下一轮决定。

没有足够流量时，不必把小样本包装成严密的对照实验。可以结合操作记录和回访解释现象，但必须保留不确定性。一次有人购买，可以成为继续研究的线索，不能单独证明渠道稳定有效。

能通过链接记录的来源，与用户自报的来源分开保存。有人看完内容再搜索产品，有人换设备回来，这些路径未必能够完整追踪。把来源未知标为未知，比填入一个看似合理的渠道更有用。

统计时写清分母和观察期。“有三个人付款”还缺少接触了多少匹配的人、花了多长时间和多少成本。不同发布时间的内容，也不宜直接比较累计结果。先尽量让观察条件一致，再讨论差异。

对于存在延迟购买的业务，可以在一个预先约定的时间点回看旧内容。这个窗口由你的使用与购买过程决定，不套用统一天数。延迟不能成为无限等待的理由：需要同时写下什么时候停止投入或调整假设。

:::

## 04 · 有效一次，接着问能否重复

![小黑测量清晰和逐渐消失的脚印，记录时间与成本](/assets/growth-with-evidence-illustrations/02-repeat.png)
*记录发生的条件，才能判断一次效果能否再出现。*

:::case 匿名实践片段 · 同样的动作，不同的时机

一位工具开发者在新内容的活跃评论区获得有效回应。后来用工具找类似帖子，却经常找到已经沉寂的旧内容。

**讨论时机变了。** 这只说明时机可能影响结果，不能证明评论推广普遍有效。

:::

| 复盘留什么 | 写什么 |
|---|---|
| 已知 | 实际发生的行为，以及人群、时间、内容、入口 |
| 未知 | 缺少哪些证据，哪些效果可能依赖偶然条件 |
| 成本 | 制作、沟通、人工交付和后续维护 |
| 下一步 | 只选一个最值得减少的不确定性 |

**一位用户与持续获客，是不同阶段的判断。** 若结果不能以可接受成本重复，就缩小下一次实验或调整方式。

:::details 进一步理解 · 复现条件与复盘方法

匿名实践片段：一位工具开发者曾在新内容的活跃评论区获得有效回应，后来使用工具寻找类似帖子，却经常找到已经沉寂的旧内容。表面动作相同，讨论发生的时间条件已经不同。这个经历只说明时机可能影响结果，不能证明评论推广普遍有效。

发现有效动作时，先记录当时的人群、时间、内容和入口，再确认这些条件能否重复取得。如果依赖偶然热点、熟人关系或不可持续的人工投入，应把它写进限制。渠道能带来一位用户，与能持续带来合适用户，是两个不同阶段的判断。

复现还要算成本。记录内容制作、沟通、人工交付和后续维护，而非只看投放费用。当投入不能继续承受时，即使产生了一些收入，也需要调整方式。

把结果分成已知、未知和下一步。已知写实际行为；未知写解释中缺少的证据；下一步只选择一个最值得减少的不确定性。若没有人进入产品，先检查触达与承接；若进入后失败，先修任务流程；若使用成功却不回来，询问任务是否真的重复发生。

填写下面的记录，再回答：这次有没有接触对的人？产品有没有承接住兴趣？结果能否以可接受的成本重复？如果答案还不清楚，把下一次实验缩小。增长工作的进展，也包括更准确地知道哪件事暂时不值得继续做。

:::
