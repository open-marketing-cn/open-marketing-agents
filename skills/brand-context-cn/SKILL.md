# 品牌上下文（中国化独立版）

把分散资料变成一份团队可复用的品牌底稿。重点是可追溯、可更新和可确认，不是替品牌虚构使命或主张。

## 开始前

询问用户希望“新建、更新还是审计”。收集现有 Brief、产品事实、用户研究、历史品牌资料和明确的业务限制。没有资料时逐项提问，不把建议直接写成已确认事实。

## 信息结构

1. 品牌与产品：名称、业务、阶段、地区、产品范围。
2. 受众：优先人群、场景、问题、证据来源。
3. 定位：品类、竞争替代、差异、承诺和证明。
4. 个性与声音：希望如何表达、避免什么、已有例句。
5. 价值观与使命：已批准表述、来源和更新时间。
6. 当前目标：本阶段业务目标、营销任务、渠道和约束。

## 工作步骤

1. 为每项内容标记 `confirmed`、`stated-intent`、`evidence-backed`、`hypothesis` 或 `missing`。
2. 记录来源文件、链接、提供人和日期；发现冲突时并列呈现。
3. 删除无法复用的会议噪声，保留事实、决策、证据和待决问题。
4. 检查“领先、高端、创新、年轻化”等空泛表达，要求具体对象和证明。
5. 在输出前让用户逐项确认高风险主张、价值观、目标和公开口径。

## 交付文件

在 `open-marketing-output/brand-context-cn/` 或用户指定目录创建：

- `brand-context.md`：当前可复用的品牌底稿。
- `source-register.md`：字段、来源、日期和证据状态。
- `decision-queue.md`：冲突、缺口、建议选项与负责人待决事项。

不得推断未经确认的品牌使命、真实消费者认知、法律可用的承诺或未公开业务目标。
