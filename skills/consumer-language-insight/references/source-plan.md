# 来源与样本计划

分析前先和用户确认：

| 项目 | 需要记录 |
|---|---|
| 品牌或品类 | 明确到可以判断是否跑偏 |
| 研究问题 | 1–3 个具体问题 |
| 目标市场 | 地区、语言或明确场景 |
| 时间窗口 | 起止日期或最近 N 天 |
| 材料来源 | 文件、平台、内容类型、预计数量 |
| 搜索与筛选 | 关键词、排序、分页、排除项 |
| 身份字段 | 默认移除头像、账号 ID、设备和精确位置 |
| 停止条件 | 数量、时间、费用或来源失效 |

规则：

- 不把搜索或 API 返回的前 N 条称为随机样本。
- 记录排序方式、时间范围、分页范围和去重规则。
- 单平台或单商品样本必须明确标注，不能外推到整个品类。
- 每批资料保留独立来源说明和处理日期。
- 联网、登录或调用付费服务前必须获得用户明确同意；没有工具也能只分析用户提供的文件。
